Update: UNION preparation amplification fixed in f8cab4b

The earlier suspects above record the investigation before attribution. A process stack sample then placed 2,891 of 2,922 maintenance samples (98.9%) inside SQLite statement preparation. The sample covers a five-second window beginning two seconds after launch. These are statistical stack counts, not an exact allocation of wall time.

Why the old operator multiplies work

The UNION emitter places the left-input query in both the representative selection and the membership exclusion. Each input contains upstream operator definitions. Repeated references drive SQLite SELECT-tree duplication and compilation through the nested chain. Merely naming the left input with a MATERIALIZED CTE still took 8.68 seconds in a trial and was discarded.

-- Structural excerpt of the OLD emitter; L and R stand for generated input SQL.
SELECT representatives FROM (L)
UNION ALL
SELECT representatives FROM (R)
WHERE key NOT IN (SELECT key FROM (L));  -- L appears a second time

-- Implemented selection: each input appears once.
SELECT c0, ..., c8, 1
FROM (
  SELECT c0, ..., c8,
         row_number() OVER (
           PARTITION BY __k ORDER BY __side, __row_identity
         ) AS __representative
  FROM (
    SELECT c0, ..., c8, __k, rowid AS __row_identity, 0 AS __side FROM (L)
    UNION ALL
    SELECT c0, ..., c8, __k, rowid AS __row_identity, 1 AS __side FROM (R)
  )
)
WHERE __representative = 1;
-- Side 0 wins; within that side the smallest exact row identity wins.

Telemetry limitation discovered during this audit

hafley-observe currently reads cumulative sqlite3_stmt_status counters. Summing profile events can include cached statements' prior population and maintenance executions. The tables above use statements observed exactly once with run=1. The raw receipts retain every observation and explicitly mark this restriction. Disabling the caller connection's cache did not disable the virtual table's separate connection-wrapper cache. No shared telemetry implementation was changed.
