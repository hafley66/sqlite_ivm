## Recommendation

Use frontier-engine as the initial crates/ivm-sqlite base if the crate is expected to serve the current extension path: it already provides database-resident catalogs and state, standalone collector reattach, and producer-consumer composition, and src/3_extension.rs exposes those lifecycle calls.
